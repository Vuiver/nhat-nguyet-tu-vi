# Web tử vi Nhật Nguyệt — bản thử nghiệm

Website: https://vuiver.github.io/nhat-nguyet-tu-vi/

Nhập ngày sinh dương lịch, giờ sinh tại Việt Nam, giới tính và năm xem hạn.
Hoặc bấm **Thử với thông tin mẫu** để xem ngay.

- Lá số 12 cung và chi tiết các sao.
- Đại vận và thông tin hạn năm, tuổi mụ.
- Tải SVG, tải JSON và in lá số.
- Tính trên trình duyệt, không gửi hoặc lưu thông tin sinh.
- Mở `index.html` trực tiếp cũng dùng được khi không có internet.

Repo này chứa bản web đã bundle thành HTML tự chứa để xuất bản trên GitHub Pages.
Không có tài khoản, thanh toán hoặc AI luận giải.
